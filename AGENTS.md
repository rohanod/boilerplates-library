# Repository Instructions

The original repository is:

- https://github.com/ChristianLempa/boilerplates-library

Before creating or implementing a requested tool in this repository:

1. Check the original repository to see whether that tool is already implemented there.
2. If it exists, clone or fetch the original repository and copy the existing implementation, along with any files it requires, into this repository.
3. Only create a new implementation when the original repository does not already contain one.

Clone the original repository into a temporary location when needed. Do not modify the original repository.
